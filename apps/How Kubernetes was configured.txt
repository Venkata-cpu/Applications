How it's set up
Cluster bootstrap: kubeadm

Storage: A dedicated LVM volume is used to keep Kubernetes data separate from the OS disk.

/dev/mapper/AutoVG2-AutoLV1  →  mounted at /apps  (XFS filesystem)
This volume holds:

/apps/kubelet/ — Kubelet working directory (pod data, state files, volumes)

Why? Keeps container workloads from filling up the root (/) filesystem. If pods use too much disk, only /apps fills up — the OS stays healthy.
